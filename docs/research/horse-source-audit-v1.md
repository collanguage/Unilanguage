## Separation

horse → 马是标准翻译。马 → 午依据通行地支配禽／生肖配属；午 → 火依据另一套五行配属。两套分类相关但不相同，组合后形成 FIRE association，不是词义定义或历史词源。

中古英语 hors 承接古英语 hors；Merriam-Webster 列古高地德语 hros 为亲缘形式。Etymonline 给出原始日耳曼语拟构 *harss-，更早来源未明。星号表示拟构，不是已见书写形式；本条不确立更早联系。此日耳曼语词史独立于拉丁语 horrēre 与希腊语 horos／horizein。

Translation Supported; cultural mapping Candidate / D / Low; component associations Supported. Historical Relation Not claimed. No phonetic/historical bonus from culture.

## Counterevidence

- horse 的英语历史词源独立，hor- 的拼写不能作为火的历史词根。
- 马 mǎ 的标准动物义是 horse，不是火；文化链不改变标准翻译。
- 午配马与午属火来自不同但关联的传统分类系统，不是马字或英语 horse 的造词过程。
- 《论衡》所记十二辰配禽不能自动证明完整的生年生肖制度；早期配属有异文与历史层次。
- 王充引述配属后反驳用五行相克解释动物制胜；传统分类不是自然因果证明。
- 文化映射不能证明跨语言同源，也不增加声音分数；片段挑选与偶然音近仍是替代解释。
- ABHOR、HORIZON、HORSE 三种作者路径不能互证 hor = 火。
