Author: Jinkai Liu. Audited 2026-09-13. Base main f0bbff3a8ec0adeef387f87ef5694352f4081e3a. No pre-existing HORIZON record/page; no backup imported.

据 American Heritage：希腊语 horos（边界）→ horizein（界定）→ horizōn (kuklos)（界定的圆周）→ 拉丁语 horizōn → 古法语 → 中古英语 orizon → 英语 horizon。法兰西学院辞典独立记载法语十三世纪 orizonte 及经拉丁语借自希腊语的路径。此处是辞书词史，不是历史录音或古音拟构。

D／低置信度：按现行 A/B/C/D 框架属于有意创造的符号与视觉桥梁。没有直接词义对应、汇聚的独立映射证据或已展示的跨案例模式；未来实验计划不自动升为 C。

Cambridge 英美参考读音均为 /həˈraɪ.zən/，表面音近评为弱。作者关注的 hor-/hori- 对应跨音节片段 /həɹ-/ 或 /həˈɹaɪ-/，不是 /hɔː/ 音节。普通话 huǒ 可描述性宽写为 [xwɔ˨˩˦]。有限近似是清擦音起首；发音部位、元音、介音、r 音与声调均有差异。这是定性评估，不是测量分数。

ABHOR：拉丁语 abhorrēre，ab- + horrēre（毛发竖起／战栗）→ 退缩／厌恶。HORIZON：希腊语 horos／horizein → 边界／界定圆周。两条历史词族分离；都映射到火，也不能推出 English hor- = 火。表面声音聚类可以支持提出假说，却不能确立共同词源。
