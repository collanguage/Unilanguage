## Two independent publication gates

1. Full JSON Schema 2020-12 validation plus dataset/reference checks.
2. Evidence/editorial validation against the separately stored approved freeze, with explicit checks for cross-layer etymological promotion, literature as history, migration provenance and unresolved references.

The production build runs both gates and adversarial regression checks before copying tracked files into a clean publication directory. It checks generated pages against the canonical data. Ignored private research and dependencies are not copied. A failed gate aborts publication.

The editorial validator is a scoped, fail-closed freeze contract, **not an automatic factual truth evaluator**. It rejects unreviewed changes to evidence-bearing fields even when the schema permits them. A future editorial decision must review a new contract; editing data and the contract together is not independent evidence and must not bypass human review. This pilot does not claim a universal validator for all future mapping types.

Regression cases include literary → historical, cultural → etymological, entry → experimental support, poem → factual name etymology, Tibetan Draft → Reviewed, Pending → selected, invented chronology, endpoint broadening, deleted scope/membership, common-origin claims and unresolved references. Original evidence grades, experiment outputs and all literary texts are checked for equality.
