01

Gate Control · Gate 控制

Templates are not authorization. Copying or completing a file does not open a gate. An automated runner must halt with AWAITING_AUTHORIZATION until the exact prerequisite manifest passes checks and the named authority approves it.
模板不等于授权。复制或填写文件不能打开 Gate。自动程序必须以 AWAITING_AUTHORIZATION 停止，直到精确的前置清单通过检查并由指定授权者批准。

Publication Boundary · 发布边界

Never publicly deploy actual private/restricted analysis keys or A/B group-identity mappings. Actual Private Research Packages stay outside the public repository. These downloadable files are blank structural templates only and contain no experiment identity key.
